Rust 程式語言的系統性學習路徑，涵蓋語言基礎、所有權模型、系統程式設計實作與小型練習專案。

## 狀態

> **實驗中**：以學習筆記與練習為主，內容將隨學習進度陸續補上。

## 學習路線

| 階段 | 主題 |
|------|------|
| 基礎 | 語法、所有權（Ownership）、借用（Borrowing）、生命週期 |
| 進階 | 泛型、trait、錯誤處理、併發（async / threads） |
| 實作 | CLI 工具、檔案處理、小型網路程式 |
| 專案 | 結合所學完成可運行的練習專案 |

## 內容規劃

- 語言基礎筆記：以《The Rust Programming Language》為主線
- 系統程式設計：記憶體管理、系統呼叫與 FFI 探索
- 練習專案：透過實作鞏固概念
